# 🏠 Mamikos Clone

Website clone dari **Mamikos** yang dibangun menggunakan **Next.js** dan **Tailwind CSS**. Project ini dibuat sebagai implementasi kemampuan frontend dalam membangun antarmuka modern yang responsif dengan struktur komponen yang reusable.

## 🚀 Demo

- **Repository**: https://github.com/rizanurmaulana/mamikos-clone

---

## 🛠️ Tech Stack

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS
- Swiper.js
- Lucide React

---

## 📦 Installation

Clone repository

```bash
git clone https://github.com/rizanurmaulana/mamikos-clone.git
```

Masuk ke folder project

```bash
cd mamikos-clone
```

Install dependencies

```bash
npm install
```

Menjalankan project

```bash
npm run dev
```

Buka browser

```
http://localhost:3000
```
